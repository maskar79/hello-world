# متجر الكتب الإلكترونية (PDF) — دفع عبر Paymob

موقع عربي لبيع ٤ كتب PDF، فيه:

- صفحة رئيسية بتعرض الكتب. لما الزائر يضغط على كتاب بتظهر نبذة تشويقية واقتباس وأهم النقاط.
- **بندل** (المجموعة الكاملة) بسعر خاص. لو حد ضاف البندل، الكتب المفردة اللي جواه بتتشال من السلة تلقائيًا.
- **أكواد خصم**: نسبة مئوية (مثلًا 50%)، أو مبلغ ثابت، أو 100% يعني مجانًا من غير ما يروح لبوابة الدفع.
- **الدفع عن طريق Paymob**: كروت، ومحافظ زي فودافون كاش، وغيرها حسب الـ integrations المفعّلة عندك.
- **زر التحميل بيفضل معطّل** لحد ما Paymob تأكد الدفع، والتأكيد ده بيتحقق منه بتوقيع HMAC. بعد التأكيد الزر بيتفعّل تلقائيًا.
- ملفات الـ PDF محمية: مش متاحة للزوار أصلًا. التحميل بيتم برابط سري خاص بكل طلب، ومعاه حد أقصى لعدد مرات التحميل.
- **كل نسخة بتتختم باسم المشتري**: كل ما حد يحمّل كتاب، السيرفر بيضيف سطر صغير أسفل كل صفحة فيه اسم المشتري (عربي أو إنجليزي) وإيميله ورقم الطلب، وبيتحفظ نفس الكلام في خصائص الملف. الملف الأصلي ما بيتغيرش. لو ملف ظهر على النت، تعرف هو جه من أنهي طلب. (`STAMP_PDFS=false` بيوقف الخاصية دي.)
- لوحة إدارة على `/admin`: متابعة المبيعات، والتأكد إن ملفات الكتب موجودة.

## التشغيل محليًا (للتجربة)

```bash
cd bookstore
npm install
cp .env.example .env        # PAYMENT_PROVIDER=mock = بوابة دفع وهمية للتجربة
npm run sample-pdfs         # ملفات PDF تجريبية (لو لسه ما حطيتش كتبك)
npm start                   # http://localhost:3000
npm test                    # الاختبارات
```

## تجهيز المحتوى

| ماذا | أين |
|---|---|
| عناوين الكتب، الأسعار، النبذة، الاقتباس، النقاط، لون الغلاف | `data/catalog.json` |
| صورة غلاف حقيقية | ضع الصورة في `public/covers/` واكتب `"cover": "/covers/book1.jpg"` |
| ملفات الـ PDF | `private/books/` — على GitHub **فقط لو الريبو Private** (انظر قسم الرفع) |
| أكواد الخصم | `data/promos.json` |

أي تعديل في ملفات `data/` بيشتغل فورًا من غير ما تعيد تشغيل السيرفر.

### أكواد الخصم (`data/promos.json`)

```json
{ "code": "HALF50",  "type": "percent", "value": 50,  "appliesTo": "all", "maxUses": null, "expiresAt": null, "active": true }
{ "code": "GIFT100", "type": "percent", "value": 100, "appliesTo": "all", "maxUses": 10,   "expiresAt": null, "active": true }
{ "code": "SAVE100", "type": "fixed",   "value": 100, "appliesTo": ["bundle-all"], "maxUses": null, "expiresAt": "2027-12-31T23:59:59Z", "active": true }
```

- `appliesTo`: إما `"all"` أو قائمة بمنتجات معينة (مثلًا `["book1", "bundle-all"]`).
- `maxUses`: عدد مرات الاستخدام، وبيتحسب بس على الطلبات اللي اتدفعت فعلًا.

## ربط Paymob (للتشغيل الحقيقي)

1. افتح حساب على [Paymob](https://accept.paymob.com) وفعّل طرق الدفع اللي عايزها (Card، Mobile Wallet…).
2. من لوحة التحكم انسخ: **Secret Key** و **Public Key** و **HMAC Secret**، وأرقام الـ **Integration IDs**.
3. في `.env` على السيرفر:
   ```
   NODE_ENV=production
   PAYMENT_PROVIDER=paymob
   BASE_URL=https://your-domain.com
   PAYMOB_SECRET_KEY=...
   PAYMOB_PUBLIC_KEY=...
   PAYMOB_HMAC_SECRET=...
   PAYMOB_INTEGRATION_IDS=1234567,7654321
   ADMIN_PASSWORD=كلمة-سر-طويلة
   ```
4. في إعدادات كل Integration في Paymob، اضبط:
   - **Transaction processed callback**: `https://your-domain.com/api/paymob/callback`
   - **Transaction response callback**: `https://your-domain.com/api/paymob/return`

   (الموقع كمان بيبعت الرابطين دول مع كل عملية دفع.)
5. جرّب الأول بمفاتيح **Test mode** وكروت الاختبار بتاعة Paymob، وبعدها حوّل للمفاتيح الحقيقية.

## الرفع مجانًا على Render

الإعداد ده **مجاني بالكامل**:

| الجزء | المكان |
|---|---|
| الموقع | Render — الخطة المجانية |
| ملفات الـ PDF | جوه الريبو ده نفسه، والريبو **Private** |
| الطلبات وأكواد الخصم المستخدمة | قاعدة بيانات Postgres مجانية على **Neon** |

ليه كده؟ السيرفر المجاني في Render بيمسح أي ملف اتحفظ عليه مع كل إعادة تشغيل. عشان كده الكتب بتيجي من الريبو، والطلبات بتتحفظ في Neon.

### ١) خلّي الريبو Private — **قبل** ما ترفع أي كتاب

GitHub → الريبو `hello-world` → **Settings** → في آخر الصفحة **Danger Zone** → **Change visibility** → **Make private**.

> ⚠️ لو رفعت الكتب والريبو Public، أي حد يقدر ينزّلها ببلاش.

### ٢) ارفع ملفات الـ PDF على GitHub

1. في الريبو، روح لفولدر `bookstore/private/books`. اتأكد إنك على فرع الموقع، مش الفرع الافتراضي.
2. اضغط **Add file → Upload files**، واسحب الأربع ملفات.
3. لازم الأسماء تكون بالظبط: `book1.pdf`، `book2.pdf`، `book3.pdf`، `book4.pdf` (أو اللي مكتوب في حقل `file` في `data/catalog.json`).
4. اضغط **Commit changes**.

حجم الملف الواحد لازم يكون أقل من 25MB لما الرفع يكون من موقع GitHub.

### ٣) اعمل قاعدة بيانات مجانية على Neon

1. ادخل على [neon.tech](https://neon.tech) واعمل حساب مجاني.
2. اعمل **Project** جديد، واختار المنطقة **AWS Europe Central 1 (Frankfurt)**. دي نفس منطقة Render، فالموقع هيبقى أسرع.
3. من **Connection string** انسخ الرابط. هيكون شكله كده:
   `postgresql://...@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

الموقع بيعمل الجداول اللي محتاجها لوحده أول ما يشتغل.

### ٤) اعمل الموقع على Render

1. ادخل على [render.com](https://render.com) بحساب GitHub، واسمح لـ Render يوصل للريبو (هو Private دلوقتي).
2. **New → Blueprint** → اختار الريبو `hello-world` والفرع → **Apply**.
3. Render هيطلب منك:
   - `DATABASE_URL`: الرابط اللي نسخته من Neon.
   - `ADMIN_PASSWORD`: كلمة سر طويلة للوحة الإدارة.
   - مفاتيح Paymob الأربعة. **لو لسه مش جاهزة سيبها فاضية**: الموقع هيشتغل عادي، والدفع هيبقى متوقف لحد ما تضيفها.
4. بعد ما الـ Deploy يخلص هيظهر لك رابط زي `https://author-bookstore.onrender.com`.
5. افتح `الرابط/admin` واتأكد إن الأربع كتب عليهم علامة ✓.

### ٥) خلّي الموقع صاحي (اختياري، بس مهم للتجربة)

السيرفر المجاني بينام بعد ١٥ دقيقة من غير زوار، وأول زائر بعدها بيستنى ٣٠–٦٠ ثانية.
عشان تمنع ده: اعمل حساب مجاني على [UptimeRobot](https://uptimerobot.com) → **New monitor** → نوعه **HTTP(s)** → الرابط `https://<الرابط>/api/catalog` → كل **5 دقايق**.

- خلي عندك خدمة مجانية **واحدة بس** صاحية على Render. الـ 750 ساعة المجانية كل شهر بتكفي خدمة واحدة بس.
- راجع شروط UptimeRobot للاستخدام التجاري قبل ما تعتمد عليه.

### ٦) لما مفاتيح Paymob تبقى جاهزة

- على Render: الخدمة → **Environment** → حط المفاتيح → **Save**. الموقع بيعيد التشغيل لوحده.
- على Paymob: حط الرابطين دول:
  - `https://<الرابط>/api/paymob/callback`
  - `https://<الرابط>/api/paymob/return`

### تعديل كتاب أو إضافة كتاب بعدين

ارفع الملف الجديد على GitHub في نفس الفولدر وبنفس الاسم. Render هيعيد نشر الموقع لوحده خلال دقايق.

### لو حبيت تنقل لخطة مدفوعة بعدين

في `render.yaml` غيّر `plan: free` لـ `plan: starter`. لو عايز ترفع الكتب من لوحة الإدارة بدل GitHub، ضيف `disk` وحط `ALLOW_BOOK_UPLOADS=true`. الطلبات هتفضل في Neon زي ما هي.

## كيف يعمل الأمان

- السعر بيتحسب على السيرفر بس. المتصفح مش بيحدد السعر.
- الطلب مش بيتعلّم "مدفوع" غير بعد ما توقيع HMAC من Paymob يتأكد، **وكمان** المبلغ المدفوع يطابق قيمة الطلب.
- كل طلب ليه رابط سري عشوائي، ومن غيره محدش يقدر يشوف الطلب أو يحمّل منه.
- الحد الأقصى للتحميل لكل كتاب بيتظبط من `MAX_DOWNLOADS_PER_BOOK` (الافتراضي 10).
